Tokens can be purchased from the Tab Menu by clicking the wallet icon next to the Credits/Tokens balance.

| Pack | Tokens | Cost |
| :---- | ----: | ----: |
| Currency | 75 Tokens | 75 Robux |
| Token Pair | 165 Tokens | 150 Robux |
| Token Bundle | 480 Tokens | 400 Robux |
| Token Box | 1,000 Tokens | 800 Robux |
| Large Token Box | 1,940 Tokens | 1,500 Robux |

The 1,500 Robux token offer has a conversion rate of about 1.2933 Tokens per Robux, rounded to 1.3 in the UI.
