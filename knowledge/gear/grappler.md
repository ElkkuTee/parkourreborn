The Grappler is an augment gear on the left arm.

It lets the player pull toward objects or walls it is fired at.

It also allows swinging in a pendulum motion on ziplines and grapple/swing points.

There are enough resources to craft two Grapplers. One can go Yank and one can go Swing. Each Grappler can only follow one upgrade path.

## Base Grappler
Effects:
* pulls the user toward any object it is fired at,
* can swing on grapple points and ziplines.

## Yank Grappler
Focus: stronger, faster pull.

Level 1:
* +25% pull strength,
* +1 ammo.

Level 2:
* +100% windup speed,
* +100% throw speed.

Level 3, unobtainable:
* +25% pull strength, +50% total,
* can reset while in use.

## Swing Grappler
Focus: longer swing and more swing freedom.

Level 1:
* +35% rope length,
* swing points reset ammo.

Level 2:
* swing on any surface.

Level 3, unobtainable:
* +15% rope length, +50% total,
* +1 ammo.

Swing II can swing on players.
