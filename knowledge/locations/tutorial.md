The Tutorial introduces basic movement to new players.

Important facts:
1. Type: Site / Building
2. Location: Center of Downtown
3. Rewards 10 Rank Stars when completed
4. Teaches base moveset:
   * Vault
   * Mantle
   * Springboard
   * Wall Climb
   * Wall Run
   * Momentum basics
5. Uses hologram demonstrations
6. Can be skipped using an elevator at the start through a gray door
7. Can be replayed through the elevator inside the Crossroads checkpoint building
8. Some base mechanics are not explicitly taught, such as High Jump and Coyote Time
9. One Duct Tape resource is located in the Tutorial building
10. Tutorial was redesigned in alpha 1.6 to take place mostly inside
11. Genesis time trial used to be inside the old Tutorial start and is now outside at the bottom of the tall concrete structure

“Treetorial” is a community name for a tree on top of the grassy building at the end of the Tutorial.
