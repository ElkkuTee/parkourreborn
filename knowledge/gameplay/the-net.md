The Net is an in-world imitation of the internet. It functions like a browser inside Parkour Reborn.

Access:
* dedicated keybind, usually Y,
* changeable in control settings,
* through the player list in the upper right.

## Browser Controls

| Control | Purpose |
| :---- | :---- |
| Search Bar | Enter website addresses |
| Refresh | Refresh current page |
| Back / Forward | Navigate browser history |
| Bookmarks | Save websites for easy access |

Invalid links return:
* error 400 Bad Request
