The Tab Menu contains multiple game menus and can be opened by:
* pressing Tab on keyboard,
* pressing Select on controller,
* clicking the red hamburger button near the Roblox menu.

## Side Menus

| Menu | Purpose |
| :---- | :---- |
| Tab Menu | Shows Credits, Tokens, and menu buttons |
| Player | Shows rank and level |
| Stats | Shows playtime, deaths, and other statistics |
| Abilities | Shows unlocked abilities with icons, details, and GIFs |
| Inventory | Contains gear, resources, key items, valuables, consumables |
| Cosmetics | Inventory for gear skins |
| Missions | Active missions; can be tracked by right-clicking |
| Music | Music tracks |
| Playlist | Manage music playlists |
| Settings | Controls, graphics, interface, gameplay options |
| Tutorials | Currently empty; intended to explain mechanics later |

## Pop-Up Menus

| Menu | Purpose |
| :---- | :---- |
| Exit to Hub | Sends player back to The Hub |
| Store | Store menu |
| Premium Inventory | Stores skins, emotes, and premium items |
| Purchase Tokens | Token purchase packs |
| Loadout | Shows equipped gear |
| Crafting | Crafting menu |
| Daily Rewards | 24-hour daily currency rewards |
