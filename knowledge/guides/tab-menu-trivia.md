* Abilities menu was accidentally added incomplete in alpha 1.1.
* It was later re-added more completely around alpha 1.14.
* It has been completed as of alpha 1.2.
* Before custom soundtrack, the game used Downtown Binary’s Aurora Album.
* Full Reborn soundtrack is planned for Spotify.
* Default Hide UI keybind is KeypadMinus, which lacks a proper icon and shows as “ERROR.”
* Coffee UI theme gives a noticeable tint to white UI characters.
* Jet Black has a similar but weaker tint.
* Other UI themes do not have this tint effect.
